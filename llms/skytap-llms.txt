# Skytap (Kyndryl Cloud Uplift)

> Skytap is a cloud service for running IBM Power (AIX, IBM i) and x86 workloads natively in Microsoft Azure, letting enterprises lift-and-shift traditional applications into self-service, on-demand virtual environments. The Skytap Cloud REST API (v1 and v2, hosted at cloud.skytap.com) programmatically manages environments, VMs, networks, templates, users and projects, and is the engine behind the official Terraform, Ansible, Vagrant and PowerShell tooling.

## APIs
- [Skytap Cloud REST API v2](https://help.skytap.com/API_v2_Documentation.html): Environments, VMs, interfaces, networks, templates, users, projects, assets, public IPs, schedules, usage, webhooks. Base URL https://cloud.skytap.com. HTTP Basic auth (username + API token).
- [Skytap Cloud REST API v1](https://help.skytap.com/API_Documentation.html): Legacy full-surface API; some operations exist only in v1.
