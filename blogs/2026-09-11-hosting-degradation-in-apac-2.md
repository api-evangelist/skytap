At this time, all of the reported symptoms should now be resolved: - Inability of some virtual machines in this region to change state (ie, run, suspend, shutdown) - Inability of some running virtual machines in this region to be saved as a template, copied or deleted This disruption may have resulted in some running Virtual Machines being returned to a powered off state.
